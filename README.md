# knitweb — field-kit monorepo

**Eén codebase, N niche-portalen.** Een field is een configbestand, geen website.
Hub: [knitweb.art](https://knitweb.art) · Fields: chemfield (live), gangfield, ledgerfield (teaser), modelfield/energyfield/codefield (coming soon).

- Spec: [`docs/SPEC-v0.1.md`](docs/SPEC-v0.1.md) — layout, field-schema, knit/fiber/vote-recordformaten, score-engine, build-contract.
- Takenbord: issues met label `agent` zijn nachtploeg-taken (Definition of Ready: DOEL/CONTEXT/ACCEPTATIE/GRENZEN/OUTPUT). Labels `nacht-1`…`nacht-6` geven de queue-volgorde.
- Agents leveren uitsluitend PR's, nooit direct naar main. CI-groen is merge-voorwaarde.
- Org-backlog live: [chemfield.github.io](https://chemfield.github.io)

Onderdeel van het VirtualV/KnitWeb go-to-market-plan (hub-and-fields, 90-dagenplan wk 1–2).
